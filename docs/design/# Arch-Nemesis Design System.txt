# Arch-Nemesis Design System

## Aesthetic Direction
**Obsidian Tech-Minimalism** – Futuristic, cinematic, clean. Deep black obsidian backgrounds with neon lime accents. Glassmorphic UI. Technical precision meets visual elegance.

## Color Palette
- **Obsidian Base**: #0a0a0a (main background)
- **Neon Lime Primary**: #ccff00 (buttons, hover, glow, accents)
- **Text**: White (headings), #9ca3af gray-400 (body), #6b7280 gray-500 (secondary)
- **Node Borders**: Emerald #10b981 (Entry), Violet #8b5cf6 (Exit), Amber #f59e0b (AI), Slate #64748b (Plain)
- **Status Colors**: Green #10b981 (added), Red #ef4444 (removed), Blue #3b82f6 (edited)

## Typography
- **Headings**: Space Grotesk, 500/700 weight, tracking -0.05em (tight)
- **Body**: Space Grotesk, 400 weight
- **Labels/Code**: JetBrains Mono, 400 weight
- **Font loading**: Google Fonts via @import

## Spacing & Layout
- **Grid size**: 60px (for background)
- **Padding base**: 4px/8px increments (px-4, py-6, p-8, etc.)
- **Gap between sections**: 2rem (gap-8) to 3rem (gap-12)
- **Max width container**: max-w-7xl

## Animations
- **Pulse glow**: 2s cubic-bezier(0.4, 0, 0.6, 1) infinite
- **Spin slow**: 3s linear infinite
- **Transitions**: 0.3s ease for all interactive states
- **Hover elevation**: subtle shadow increases + slight scale/opacity change

## Responsive Breakpoints
- Mobile: < 768px (flex column, vertical layout)
- Tablet: 768px - 1024px (2-column grids)
- Desktop: > 1024px (multi-column, full features)
- Diagram mobile: becomes vertical list instead of left-to-right flow

## Dark Theme Only
No light mode. Obsidian is the single, permanent aesthetic. All components designed for dark context.
